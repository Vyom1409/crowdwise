🔬 Empirical Validation Methodology:
• Dataset: 2,559,899 Electronic Ticketing Machine (ETM) records across 1,628 active Delhi transit routes.
• Evaluation Method: Chronological holdout evaluation splitting October 01–24 (training/fitting) against October 25–31 (out-of-sample evaluation across 575 validation corridors).
• Comparison: Delivers an 87.2% predictive alignment gain over static timetables (+65.8% accuracy gain).
🛣️ Road Routing & Caching Architecture:
• Provider: OpenStreetMap / OSRM v5 (Driving Profile with actual road curves).
• Waypoint Chunking: 18-waypoint sub-chunks with boundary coordinate stitching.
• Caching Strategy: Deterministic SHA-256 disk cache in backend/osrm_cache/ with atomic writes.
• Fallback: Automatic fallback to straight lines with explicit user warnings on network drop.
